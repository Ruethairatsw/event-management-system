Event Management System – Database Design

Project Overview

This project is a university group project focused on designing a database for an Event Management System.

The system is designed to manage event organizers, events, participants, and registrations.

Project Objectives

* Design a database structure for an event management system.
* Identify entities, attributes, and relationships.
* Create an Entity Relationship Diagram (ERD).
* Define Primary Keys and Foreign Keys.
* Prepare a Data Dictionary.

Tools & Concepts

* Database Design
* Entity Relationship Diagram (ERD)
* Data Dictionary
* Primary Key (PK)
* Foreign Key (FK)
